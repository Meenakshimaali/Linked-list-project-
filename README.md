# 🎵 Playlist Manager using Linked List (C++)

## 📌 Project Overview
This project is a **Music Playlist Management System** developed in **C++**, based on both **Singly Linked List** and **Doubly Linked List** concepts.

It provides an interactive **menu-driven interface** where users can manage songs dynamically. Each song is stored as a node containing details like **Song ID, Artist Name, and Song Title**.

## 🚀 Features
✅ Choose implementation:
- Singly Linked List
- Doubly Linked List

🎶 Playlist operations:
- Add songs
- Delete songs
- Search songs by artist name
- Display playlist
- Count total songs
- Forward and backward traversal

## 🧠 Concepts Used
- Data Structures
- Singly Linked List
- Doubly Linked List
- Classes & Objects
- Pointers
- Dynamic Memory Allocation
- Menu-driven Programming
